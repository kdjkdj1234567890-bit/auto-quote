# 💛 편한 견적서 — "얼마예요?" 카톡에 링크 하나로 끝

**타겟 고객**: 동네 사장님 (청소·이사·인테리어 등 견적 문의가 많은 가게).
개발자가 아니라 **돈을 쓰는 사장님**이 고객입니다. 화면의 모든 문구는 사장님 말로 썼고,
어려운 말은 하나도 없습니다. 톤은 따뜻하게 — "편하게", "안심", "걱정 마세요".

## 왜 만들었는가

> "높은 가치는 느끼는 사람들에게 전달되어야 한다"

주말 저녁, 가족과 밥 먹다가 "얼마예요?" 카톡이 오면 — 사장님은 밥숟가락을 놓고 답해야 했어요.
그 시간을 돌려드리려고 만들었어요.

- **사람을 사람으로**: 손님도 사장님도 숫자가 아니에요.
- **정직**: 견적은 단가표 그대로, 숨김없이 보여드려요.
- **다크패턴 금지**: 몰래 결제 유도 같은 건 절대 없어요.
- **따뜻함**: "편하게", "안심하세요", "걱정 마세요"가 기본 말투예요.
- **신뢰**: 접수된 예약은 하나도 빠뜨리지 않아요.
- **겸손**: 이 도구는 보조일 뿐, 주인공은 언제나 사장님이에요.
- **인내**: 주말 밤 11시의 견적 문의에도 지치지 않아요.

**이 데이터는 10년 후에도 사장님의 것입니다.**
손님들이 확인한 견적, 받아낸 예약, 사장님이 정한 단가표는 가게의 자산이에요.
언젠가 가게를 물려주는 날(**가게 이어받기**), 그 노하우가 함께 이어지길 바랍니다.

**사명 선언문**: "우리는 사장님의 일을 세상이 알아주게 만듭니다."

## 사장님의 짜증 (이 데모가 푸는 문제)

> "오늘 23번째 '얼마예요?' 카톡이 왔습니다. 같은 답을 23번 했습니다."

"30평 입주청소 얼마예요?" — 매번 평수를 묻고, 옵션을 묻고, 계산기를 두드리고, 답장합니다.
하루 23번이면 47분. 그 시간에 36만원짜리 청소 한 건을 끝낼 수 있었어요.
100번째 답변에서는 감정이 터집니다. **반복에서 해방**시켜주는 게 이 데모입니다.

## 어떻게 돌아가나요 (1분이면 이해돼요)

1. 카톡으로 "30평 입주청소 얼마예요?"가 와요.
2. 사장님은 **견적 링크 하나**만 보냅니다. 일하던 손은 그대로.
3. 손님이 직접 평수를 고르고, 옵션을 고르면 **금액이 바로** 나옵니다.
4. 마음에 들면 **바로 예약**까지. 사장님은 확인 전화 한 통이면 돼요.

핵심 기능(평수 고르기 → 견적 확인 → 예약)까지 **3번 클릭**이면 됩니다.
60대 사장님도 쓸 수 있게 버튼도 글씨도 크게 만들었습니다.

## 이걸 쓰면 월 ○○만원 아껴요

데모 첫 화면의 계산기로 직접 확인할 수 있어요.
하루 23번 × 한 번 답하는데 2분 = **한 달 23시간** 절약.
그 시간에 청소(2시간·36만원) 11건을 더 하면 **월 396만원**입니다.
아낀 시간에 일 한 건만 더 해도 남는 장사예요.

## 실행 방법

```bash
bash run.sh
```

- 기본 주소: **http://localhost:5010**
- 5010번 포트가 이미 사용 중이면 5011, 5012… 순서로 자동 전환됩니다.
  (실행 시 터미널에 표시되는 주소를 확인하세요)
- 처음 실행하면 기본 단가표가 자동으로 들어갑니다.
- 종료: `Ctrl+C`
- 기술: Python Flask + SQLite. 외부 API·유료 서비스 없이 전부 동작합니다.

## 화면 구성

| 화면 | 설명 |
|---|---|
| `/` (첫 화면) | 짜증 모먼트 오프닝 — "오늘 23번째 '얼마예요?' 카톡"을 숫자와 카톡 화면으로 재현한 뒤 "5분 안에 직접 써보세요"로 전환 |
| `/start` | "어떤 가게세요?" — 청소/이사/인테리어 선택, 가치 계산기, 사장님 화면 링크 |
| `/q/청소` `/q/이사` `/q/인테리어` | 손님용 견적 화면 — 평수 슬라이더·옵션 체크 → 금액 실시간 재계산, 견적서(부가세 10%·유효기간 7일), 견적 링크 복사(카톡 공유 시뮬레이션), 예약하기 |
| `/book` | 예약 접수 — 이름/연락처/희망일 입력 (형식 검증 + 친절한 안내) |
| `/owner` | 사장님 화면 — 단가표 직접 수정(손님 화면 즉시 반영), 손님이 확인한 견적 이력, 접수된 예약 목록 |

## 핵심 어필 포인트

- **감정적 해방**: "같은 말 100번 반복하지 마세요" — 기술 자랑이 아니라 사장님의 짜증을 덜어주는 이야기
- **숫자로 증명**: 23번·47분·월 396만원을 첫 화면과 계산기에서 바로 보여줌
- **3클릭 완성**: 평수 고르기 → 견적 확인 → 예약 접수까지 3번 클릭
- **사장님 말투 전면**: 개발자 용어 0개, 60대도 읽히는 큰 글씨·큰 버튼
- **단가표는 사장님 것**: /owner에서 숫자만 바꾸면 손님 화면에 바로 반영
- **🔗 다른 9개와 연결됩니다** (10종 패키지)
